# Mercurius

**Type :** portail public belge d'e-facturation  
**Champ :** émission manuelle et suivi de factures électroniques structurées vers les pouvoirs publics  
**Usage :** solution de transition ou de dépannage pour les fournisseurs qui ne disposent pas encore d'un flux `ERP` ou comptable natif

## Description

[[entities/mercurius|Mercurius]] est un portail public belge utilisé pour encoder manuellement des factures électroniques et suivre leur traitement. Il ne remplace pas le réseau `Peppol`, mais sert de point d'entrée opérationnel lorsque l'entreprise n'est pas encore complètement équipée d'un outil d'e-facturation intégré.

## Rôle pratique

Dans le corpus actuel, Mercurius apparaît surtout comme :

- un canal accepté par certains adjudicateurs publics aux côtés de `Peppol` ;
- un outil de transition pour émettre une facture structurée conforme ;
- un portail utile pour le suivi des flux et le contrôle de bonne réception.

## Importance pour les marchés publics HVAC

Pour une entreprise HVAC, Mercurius n'est pas un sujet de conception technique, mais un point de friction administratif possible en exécution. Il faut vérifier avant le premier acompte :

- si le pouvoir adjudicateur accepte `Peppol`, [[entities/mercurius|Mercurius]] ou les deux ;
- quelles références de marché doivent être encodées ;
- et si l'entreprise doit l'utiliser seulement en secours ou comme canal principal.
