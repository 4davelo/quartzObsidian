# e-Procurement

**Type :** plateforme belge de marchés publics  
**Champ :** publication des marchés, accès aux documents, forum de questions et dépôt électronique des offres  
**Usage :** canal opérationnel de consultation et de remise d'offre pour les marchés publics belges

## Description

`e-Procurement` est la plateforme belge utilisée pour publier des marchés publics, mettre à disposition les documents du marché et introduire les offres par voie électronique lorsque la procédure l'exige.

Pour une entreprise HVAC, ce n'est pas un référentiel technique : c'est un point de contrôle administratif critique dans la préparation d'une offre.

## Rôle pratique

Dans le corpus actuel, `e-Procurement` intervient surtout pour :

- récupérer les documents de marché et les éventuels addenda ;
- poser ou consulter les questions via le forum lorsque le marché le prévoit ;
- déposer l'offre avant l'échéance ;
- vérifier les exigences de signature électronique et de rapport de dépôt.

## Importance pour les marchés publics HVAC

Avant de remettre prix, il faut vérifier sur `e-Procurement` :

- la dernière version des documents publiés ;
- les réponses aux questions et rectificatifs ;
- le mode de dépôt accepté ;
- les exigences de signature ;
- et les fichiers structurés à joindre, notamment le formulaire, le métré ou l'inventaire.
