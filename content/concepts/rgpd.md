# RGPD

## Définition

Dans le tome A, le `RGPD` n'est pas traité comme une mention générique de conformité. L'article `A6.1` pose un véritable cadre contractuel pour les cas où l'adjudicataire traite des données à caractère personnel pour le compte de l'adjudicateur.

## Position de l'adjudicataire

Lorsque l'adjudicataire traite des données pour le compte de l'adjudicateur :

- l'adjudicateur est le responsable du traitement ;
- l'adjudicataire agit comme sous-traitant au sens du `RGPD`.

Le tome A impose alors un ensemble d'obligations sur la confidentialité, la sécurité, le registre des traitements, les audits et les transferts de données.

## Obligations principales rappelées par le tome A

- traiter les données uniquement sur instruction de l'adjudicateur ;
- limiter le traitement aux finalités, types de données et catégories de personnes visés par le marché ;
- imposer une obligation de confidentialité démontrable aux personnes ayant accès aux données ;
- tenir un registre des activités de traitement ;
- mettre les données à disposition de l'adjudicateur ou les détruire selon ses instructions ;
- ne pas transférer les données hors `UE`, ni hors territoire belge sans autorisation écrite préalable lorsque le marché l'exige ;
- ne pas recourir à un autre sous-traitant sans autorisation.

## Sécurité et incidents

Le tome A exige aussi :

- une politique et un plan de sécurité actualisés ;
- un contrôle des accès, une séparation des fonctions et une journalisation adaptée ;
- la désignation d'un délégué à la protection des données lorsque le cadre l'impose ;
- une notification de toute violation de données à l'adjudicateur **au plus tard dans les 24 heures** après constat.

## Si l'adjudicataire ne traite pas de données pour le compte de l'adjudicateur

Même hors schéma de sous-traitance de données, le tome A impose à l'adjudicataire de respecter les obligations générales du `RGPD` et de signaler proactivement si des accords complémentaires sont nécessaires.

## Importance pour HVAC

Le sujet `RGPD` peut sembler périphérique dans un lot HVAC, mais il devient concret dès qu'il y a :

- supervision technique avec accès à des bâtiments occupés ;
- gestion de badges, logs, alarmes ou historiques d'occupation ;
- maintenance avec plateformes connectées ;
- transmission de données de contact, d'intervenants ou d'usagers.

Le tome A permet donc de traiter la conformité données personnelles comme une vraie exigence de marché, pas comme une clause de bas de page.
