# CSC — Cahier Spécial des Charges

## Définition

Le Cahier Spécial des Charges (CSC) est le document de spécification propre à un projet déterminé. Il constitue la pièce contractuelle centrale du marché et active, complète ou adapte les clauses du [[entities/cctb|CCTB]].

## Relation avec le CCTB

Le CSC s'appuie sur le [[concepts/cadre-cctb|Cadre CCTB]] :

- il référence les articles du [[entities/cctb|CCTB]] par leur numéro d'index plutôt que de les recopier ;
- il précise les choix entre les options prévues dans le CCTB ;
- il complète ou déroge aux prescriptions CCTB selon les spécificités du projet ;
- il fixe les annexes, plans, inventaires et autres pièces qui composent les [[concepts/documents-du-marche|Documents du Marché]].

Le tome A rappelle que, lorsqu'il y a contradiction entre pièces contractuelles, l'ordre d'interprétation est :

1. les plans ;
2. le CSC ;
3. les métrés.

## Contenu typique d'un CSC

Un CSC complet comprend généralement :

- les spécifications du projet et les références CCTB applicables ;
- les plans, métrés, formulaires et modèles de documents ;
- les [[concepts/pss|PSS]] requis par corps de métier ;
- les exigences de [[concepts/coordination-de-chantier|Coordination de Chantier]] ;
- les exigences du [[concepts/dossier-de-cloture|Dossier de Clôture]] ;
- les modalités de [[concepts/gestion-des-dechets-de-construction|Gestion des Déchets de Construction]] ;
- les exigences de [[concepts/sous-traitance|Sous-traitance]], d'assurances, de paiements et de réceptions.

## Rôle dans la procédure de marché

Le CSC est la base des offres remises par les entrepreneurs. Il ne faut donc pas le lire comme une simple description technique, mais comme le document qui transforme le CCTB en obligations de marché opposables à l'entreprise.

L'intégralité de l'offre engage l'entrepreneur : les prix sont réputés couvrir toutes les prestations décrites ou nécessaires à la bonne exécution, même si certaines ne sont pas détaillées ligne par ligne.

## Spécifications T6 à verrouiller dans le CSC

Le tome T6 montre que le [[concepts/csc|CSC]] doit fixer explicitement un grand nombre de choix techniques. À défaut, les options par défaut du CCTB ou l'interprétation de l'entrepreneur prendront le relais.

Il faut notamment y verrouiller :

- le type de système de ventilation, les débits, les niveaux de régulation et les performances de récupération ;
- les classes acoustiques, traitements antivibratiles et silencieux ;
- les matériaux, épaisseurs et documents attendus pour le calorifugeage ;
- les générateurs retenus, les fluides frigorigènes, les garanties, les rendements et les seuils de bruit ;
- les exigences de [[concepts/eau-chaude-sanitaire|Eau Chaude Sanitaire]], de [[concepts/installations-sanitaires|Installations Sanitaires]] et de récupération d'eau ;
- les niveaux de résistance au feu, les clapets, grilles, cartouches ou autres solutions de compartimentage ;
- les essais, rapports, plans as-built et autres pièces du [[concepts/dossier-de-cloture|Dossier de Clôture]].

## Ce qu'une entreprise doit y vérifier

- le périmètre réel du lot et ses interfaces ;
- les renvois aux articles CCTB activés ;
- la composition des [[concepts/documents-du-marche|Documents du Marché]] ;
- les pièces du [[concepts/contenu-de-loffre|Contenu de l'Offre]] ;
- les exigences d'[[concepts/agrement-entrepreneurs|agréation]] et de [[concepts/sous-traitance|Sous-traitance]] ;
- les clauses de [[concepts/revision-des-prix|Révision des Prix]], d'[[concepts/avances-sur-marche-public|avance]], de garantie et de réception ;
- les exigences de [[concepts/dossier-de-cloture|Dossier de Clôture]] ;
- les obligations supplémentaires liées au [[concepts/pss|PSS]], au [[concepts/dnsh|DNSH]] ou aux [[concepts/clauses-sociales|Clauses Sociales]].
