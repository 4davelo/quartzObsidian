# Cadre CCTB

## Définition

Le cadre [[entities/cctb|CCTB]] (Cahier des Charges Type Bâtiments) est le système normatif de référence pour les projets de construction en Wallonie. Il fixe des prescriptions techniques et administratives destinées à structurer les marchés, les spécifications et l'exécution des travaux.

## Autorité légale

Le CCTB fait autorité comme document de référence général pour :

- les **marchés publics** passés par les services publics de Wallonie ;
- les **travaux subsidiés** par la Région wallonne et la Fédération Wallonie-Bruxelles.

Il est intégré contractuellement via la mention dans le [[concepts/csc|CSC]] du projet. Le tome A précise que le CCTB fait partie intégrante des documents du marché dont le soumissionnaire doit tenir compte pour rédiger son offre.

## Place du tome A

Le tome A est la porte d'entrée administrative du CCTB. Il sert de gabarit aux clauses administratives du marché et couvre notamment :

- le champ contractuel ;
- la composition des [[concepts/documents-du-marche|Documents du Marché]] ;
- la [[concepts/passation-de-marche|passation]] ;
- l'exécution, les paiements, les garanties et les réceptions.

## Place du tome T6 pour HVAC

Pour les offres HVAC, le tome T6 joue le rôle de porte d'entrée technique. C'est lui qui :

- transforme le cadre administratif en postes techniques activables dans le [[concepts/csc|CSC]] ;
- fixe les options par défaut, les variantes admises, les débits, pressions, températures, niveaux de performance et références normatives ;
- rattache les lots HVAC aux exigences de [[concepts/qualite-de-lair-interieur|Qualité de l'Air Intérieur]], d'acoustique, de [[concepts/peb|PEB]], de feu, d'essais et de documentation.

## Comment utiliser le CCTB dans un CSC

Un [[concepts/csc|CSC]] bien structuré procède généralement ainsi :

1. référence les articles CCTB par leur index ;
2. complète les choix, variantes et seuils laissés ouverts ;
3. indique les précisions, compléments et dérogations nécessaires ;
4. raccorde les clauses administratives aux exigences techniques des tomes concernés.

## Lecture utile côté entreprise

Pour une entreprise, le CCTB doit être lu comme un **socle contractuel implicite** :

- certaines obligations ne sont pas répétées partout dans le [[concepts/csc|CSC]] ;
- les renvois à un article CCTB suffisent souvent à rendre ses prescriptions pleinement applicables ;
- l'analyse du marché suppose donc de croiser les articles activés avec les plans, les métrés et les annexes.

## Maniabilité sur chantier

Le CCTB est directement consultable sur chantier via le portail des bâtiments du SPW. Cela en fait un document de travail opérationnel, pas seulement un référentiel théorique.

## Conformité et limites

Les prescriptions du CCTB sont formulées de manière à éviter les monopoles ou descriptions de marque, même implicites. Le tome A rappelle aussi que les clauses générales ou contrats types propres aux soumissionnaires, sous-traitants ou tiers sont réputés non écrits.
