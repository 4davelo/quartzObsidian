# Avances sur Marché Public

## Définition

L'avance est le paiement d'une partie du marché avant service fait et accepté. Pour une entreprise, c'est un levier de trésorerie potentiellement très utile au démarrage.

## Ce que prévoit le tome A

Le tome A distingue :

- les avances obligatoires, dans certains cas prévus par la réglementation ;
- les avances volontaires, si le marché les prévoit.

Pour les PME, les taux dépendent de la taille de l'entreprise. Pour certains marchés nécessitant des investissements préalables importants, des taux plus élevés peuvent être prévus dans les limites légales.

## Avances obligatoires

Le tome A distingue deux grands cas.

### 1. Certaines procédures négociées sans publication préalable

Dans certaines hypothèses de procédure négociée sans publication préalable, l'avance est obligatoire sur demande écrite de l'adjudicataire.

Le tome A rappelle notamment :

- un plafond légal de **225.000 EUR TVAC** ;
- un taux de **15 %** par défaut de la valeur de référence ;
- un maximum légal de **20 %**, voire **50 %** dans certains cas d'investissements préalables considérables ;
- une demande à introduire avant le premier état d'avancement auprès du [[concepts/fonctionnaire-dirigeant|Fonctionnaire Dirigeant]].

### 2. Les autres procédures pour les PME

Pour les autres procédures, le régime obligatoire vise les PME, avec les taux suivants rappelés par le tome A :

- **micro-entreprise** : 20 % de la valeur de référence ;
- **petite entreprise** : 10 % par défaut ;
- **moyenne entreprise** : 5 % par défaut.

Pour les marchés exigeant des investissements préalables importants, le taux peut être relevé dans les limites légales, jusqu'à **50 %** selon le cas prévu.

## Valeur de référence et imputation

Le tome A précise que la valeur de référence dépend de la durée du marché :

- montant attribué TVAC si la durée est inférieure ou égale à 12 mois ;
- proratisation annuelle si la durée est supérieure à 12 mois ;
- valeur attribuée par mois multipliée par 12 si la durée est indéterminée.

Le paiement intervient en principe dans les **30 jours calendrier** à compter de la demande valablement introduite.

Lorsque des paiements intermédiaires sont prévus, l'imputation par défaut de l'avance s'opère ainsi :

- 50 % de l'avance lorsque 30 % du marché est exécuté ;
- le solde lorsque 60 % du marché est exécuté.

Le tome A ajoute que, pour le calcul de l'avance, il n'est pas tenu compte des tranches conditionnelles ni des reconductions.

## Avances volontaires

Le marché peut aussi prévoir une avance volontaire, avec :

- plafond de 225.000 EUR TVAC ;
- taux défini par le marché dans les limites légales ;
- mêmes logiques de valeur de référence, de demande préalable et d'imputation.

## Réflexes côté entreprise

- vérifier si une demande d'avance est possible ;
- respecter le bon moment de demande, avant le premier état d'avancement ;
- adresser la demande au [[concepts/fonctionnaire-dirigeant|Fonctionnaire Dirigeant]] ;
- comprendre comment l'avance sera imputée ensuite sur les paiements.

Il faut aussi anticiper les pièces probantes demandées pour établir la taille de l'entreprise lorsque le régime PME s'applique : attestations ONSS, états financiers, documents traduits si nécessaire.

Le marché dont le délai d'exécution est inférieur à deux mois ne donne pas obligatoirement lieu à une avance obligatoire, mais peut encore prévoir une avance volontaire.

## Importance pour HVAC

Les lots HVAC mobilisent souvent rapidement de la trésorerie : commandes d'équipements, régulation, outillage, préfabrication, sous-traitants, mise au point. Une avance bien maîtrisée peut réduire le besoin en fonds de roulement du lot, surtout lorsque la chaîne d'approvisionnement démarre avant les premiers acomptes mensuels.
