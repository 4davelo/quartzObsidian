## Structure type d'un descriptif FAÇADES

### Points clés :
- **Éléments décrits** : échafaudages, enduits, peintures, revêtements plastiques épais (RPE), bardage, finitions.
- **Échafaudages** : peuvent être inclus dans la DPGF/DQE ou simplement mentionnés dans les Caractéristiques techniques communes ou Dispositions générales. Possibilité de [[Sous-traitance]] (autorisation via CCAP) ou création d'un lot spécifique pour projets d'envergure.
- **Variantes possibles** : ITE (Isolation Thermique Extérieure).
- **Finitions** : couvre-joints, couveretines, profilés de finition. 

### Remarque :
Les structures proposées sont indicatives et doivent être adaptées au dossier spécifique.

### *Nota 1*

Ainsi intégrés dans la description détaillée des ouvrages du CCTR, les échafaudages deviennent un OE qui aura un montant dans la DPGF ou le DQE, ce qui en fait un élément explicite de comparaison des offres de prix.

Il est possible que la MOE préfère ne pas les décrire et préciser les obligations de l'entreprise dans les Caractéristiques techniques communes, voire dans les Dispositions générales. Dans ces deux derniers cas, les échafaudages n'apparaissent pas dans la DPGF ou le DQE.

### *Nota 2*

L'entreprise titulaire du lot façades préfère parfois sous-traiter la conception et le montage des échafaudages à une entreprise spécialisée. Le CCAP doit autoriser le recours à un sous-traitant.

### *Nota 3*

Sur un projet d'envergure la MOE peut décider de créer un lot échafaudages, car ceux-ci seront utilisés par plusieurs lots (façades, menuiseries extérieures, couverture-zinguerie, etc.).
