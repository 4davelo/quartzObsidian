La production d’[[Eau Chaude Sanitaire]] peut être collective ou individuelle, avec des configurations de réseau distinctes.

**41.4.1 Production collective**  
La production collective, souvent couplée au système de chauffage, peut être instantanée ou stockée dans un ballon collectif. Les modes de gestion varient selon les configurations.

**41.4.2 Production individuelle**  
Deux cas principaux :  
- Chauffage collectif sans production d’eau chaude, celle-ci étant assurée individuellement (ballon électrique, chauffe-bains, etc.).  
- Chauffage et eau chaude collectifs, mais avec gestion individuelle via un système centralisé (boucles primaires séparées ou uniques). Un module thermique d’appartement (MTA) peut être utilisé pour produire l’[[Eau Chaude Sanitaire]] individuelle.

**41.4Production d’[[Eau Chaude Sanitaire]] par couplage avec le chauffage central**

Selon que le système est collectif ou individuel, la configuration du réseau de distribution varie grandement. 

**41.4.1 Production collective d’eau chaude** 

Cette configuration est la plus fréquente. Généralement, la production est réalisée par le même système que celui du chauffage (elle peut l’être également par un dispositif séparé). Elle est soit instantanée, soit stockée dans un ballon d’eau chaude collectif. Ces possibilités sont schématisées sur la **fgure [41.4](288_41.4_production_deau_chaude_sanitaire_par_couplage_avec_le_chauffage_central.md)** , où elles se trouvent différenciées seulement par le mode de gestion envisagé.

**41.4.2 Production individuelle d’eau chaude**

- la production collective ne concerne que le chauffage (par exemple, plancher électrique ou chaufferie non mixte) ; la production d’eau chaude est individuelle avec des systèmes déjà évoqués : ballon électrique, chauffe-bains, etc. ( **fg. 38.1** et **fg. 38.2** ) ; 

- •  la production collective concerne le chauffage et l’eau chaude ( **fg. 38.3** ) ; ce dispositif ne peut se concevoir que dans le cas où l’usager gère individuellement ses besoins à partir d’une boucle collective. Il s’agit : 

du système de chauffage individuel centralisé, dans lequel la distribution primaire est initialement composée de deux boucles : l’une pour le chauffage, l’autre pour l’eau chaude, du système collectif individualisé, dans lequel la distribution primaire est effectuée par une seule boucle d’eau chaude ; un module thermique d’appartement (MTA) est implanté sur la boucle individuelle de chauffage et comporte une échangeur qui assure la production d’[[Eau Chaude Sanitaire]] individuelle.
