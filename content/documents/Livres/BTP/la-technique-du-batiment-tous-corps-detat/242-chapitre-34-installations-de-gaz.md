#### Chapitre 34 Installations de gaz

Deux types de gaz naturels sont distribués : ceux dits « de type H », dont le pouvoir calorifique supérieur est compris entre 10,7 et 12,8 kWh/m[3] ; ceux dits « de type B (ou L) », dont le pouvoir calorifique supérieur est compris entre 9,5 et 10,5 kWh/m[3] . 

Le seul gaz de type B (ou L) est le gaz de Groningue (Pays-Bas) qui est distribué en région Hauts-de-France. 

Tous les autres gisements connus fournissent ou fourniront des gaz de type H. Ce sont actuellement, pour ce qui est de la France : le gaz norvégien, lequel représentait en 2014 presque 40 % de 

l’approvisionnement ; 

le gaz russe ; 

le gaz hollandais ; 

le gaz algérien.
