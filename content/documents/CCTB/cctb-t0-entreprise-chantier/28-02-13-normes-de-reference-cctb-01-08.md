#### 02.13 Normes de référence [[entities/cctb|CCTB]] 01.08

**DESCRIPTION** 

**Définition / Comprend** 

Les normes de référence sont celles mentionnées dans le texte des éléments : 

- Du [[entities/cctb|CCTB]] qui sont d'application dans le présent marché, 

- Du cahier spécial des charges du présent marché. 

Lorsque ces normes sont identifiées par un texte du type [ _code court_ ], leur identification complète figure dans le  Catalogue des documents de référence (CDR).  (Voir également le point "DOCUMENTS DE REFERENCE, NORMES DE REFERENCE OU EQUIVALENCE NORMES EUROPEENNES" de l'élément [00.3 Structure & conception](08_00.3_structure_conception_cctb_01.12.md)).
