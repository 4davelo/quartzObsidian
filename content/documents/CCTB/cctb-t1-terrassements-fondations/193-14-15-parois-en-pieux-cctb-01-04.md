  **14.15 Parois en pieux CCTB 01.04**

  Les parois en pieux sont classées en deux types principaux :
  - **Type 1 : Parois de pieux sécants** (pieux s’emboîtant les uns dans les autres) – Référencées dans l'Infofiche Buildwise 56.03, elles détaillent l'exécution, les techniques et dimensions applicables.
  - **Type 2 : Parois de pieux tangents** (pieux placés côte à côte) – Référencées dans l'Infofiche Buildwise 56.04, elles couvrent également l'exécution, les techniques et dimensions applicables.

  Ces documents sont essentiels pour le choix et la mise en œuvre de ces soutènements.

#### 14.15 Parois en pieux [[entities/cctb|CCTB]] 01.04 

DOCUMENTS DE RÉFÉRENCE 

**Exécution** 

[Buildwise Pathologie Infofiche 56.03, Parois de pieux de type 1 : pieux s’emboîtant les uns dans les autres (paroi de pieux sécants)]

L'Infofiche sur les parois de pieux de type 1, également appelées parois de pieux sécants et constituées de pieux s’emboîtant les uns dans les autres est essentielle si l'on opte pour ce type de soutènement. Elle s'attarde notamment sur les aspects d’exécution, les techniques et les dimensions d’application pour ces soutènements. 

[Buildwise Pathologie Infofiche 56.04, Parois de pieux de type 2 : pieux placés l’un à côté de l’autre (paroi de pieux tangents)] 

L'Infofiche sur les parois de pieux de type 2, également appelées parois de pieux tangents et constituées de pieux placés l'un à côtés de l'autre est essentielle si l'on opte pour ce type de soutènement. Elle s'attarde notamment sur les aspects d’exécution, les techniques et les dimensions d’application pour ces soutènements.
