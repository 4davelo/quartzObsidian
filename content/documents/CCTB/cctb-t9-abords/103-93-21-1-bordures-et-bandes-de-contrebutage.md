  **93.21.1 Bordures et bandes de contrebutage**

  **a. Pierre naturelle (CCTB 01.09)**
  - Matériaux : caractéristiques lithologiques, dimensions, finitions et types (AI, AII, BI, BII, CI, CII, DI, DII, TEC).
  - Exécution : préciser saillie/enterré, rayons de courbure, bordures courtes pour courbes < 15 m.
  - Mesurage : longueur nette (m), marché QF.

  **b. Béton préfabriqué (CCTB 01.11)**
  - Matériaux : types (IA, IB, IC, ID, IE, IF), dimensions, éléments droits/courbes, options béton blanc.
  - Exécution : saillie/enterré, fondations, collage, courbes < 15 m.
  - Mesurage : longueur nette (m), marché QF.

  **c. Sciage (CCTB 01.09)**
  - Mesurage : unité P, marché QF.

  **d. Béton coulé sur place (CCTB 01.09)**
  - Description : éléments linéaires conformes aux profils préfabriqués.
  - Mesurage : longueur nette (m), marché QF.

  **e. Éléments spéciaux préfabriqués (CCTB 01.09)**
  - Matériaux : types (IA, IB, IC, ID, IE, IF), angles (90°/135°), transitions, bordures directionnelles.
  - Mesurage : unité P, marché QF.

  **f. Réemploi (CCTB 01.11)**
  - Exécution : origine (chantier/dépôt) pour pierre naturelle, bandes préfabriquées, bordures béton (> ou ≤ 100 mm).
  - Mesurage : longueur nette (m), marché QF.
